# Exam OR Triage

Read the actual task README and data schema. Produce **at most one page**:
1. Decision variables, hard constraints (each testable), soft objectives (units/directions)
2. Explicit assumptions and questions that would change feasibility
3. Feasible baseline implementable quickly; one improvement algorithm
4. Solver choice only if dependency/setup cost justified; timeout and heuristic fallback
5. Independent feasibility checker and score comparator with edge cases

Do **not** modify code or data. Prefer a feasible, measurable result over sophisticated unfinished optimization. If separate agent execution is unavailable, use this as an instruction to the Main Codex. Return actionable specification, not a lecture.
