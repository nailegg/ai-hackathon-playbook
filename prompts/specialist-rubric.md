# Rubric Specialist (읽기 전용 보조 세션)

> **대상: 두 번째 Codex 세션에 붙여 넣는 프롬프트.** 사람이 Terminal 2에서, 해당 전략 문서의 "허용되는 분할" 조건에 맞을 때만 띄운다. 동시에 1개, 10분 안에 끝낸다. Main 세션은 이 세션을 띄우지 않는다.

```text
과제 루트에서 실행 중이다. 너는 읽기 전용 보조 세션이다. 과제 README.md와 CONTRACT.md를 먼저 읽어라. 코드·데이터·다른 문서는 수정하지 말고 결과는 RUBRIC.md 한 파일에만 쓴다. 다른 세션이 같은 폴더에서 구현 중이니 서버를 띄우거나 종료하지 말고 패키지를 설치하지 마라. 10분 안에 끝내고, 명시된 사실과 가정을 구분해 1페이지 이내로 쓴다.
평가 대상과 CONTRACT 6절을 보고 평가 축(정확성·근거성·유보·형식 등)별 통과 기준, 결정론적으로 검사할 수 있는 항목과 판정이 필요한 항목의 구분, 반례 10개, 사람이 확인할 샘플 선정 기준을 쓴다.
```
