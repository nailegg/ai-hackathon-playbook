# 첫 수직 기능 구현

```text
확정된 README 요구사항과 제공 데이터를 기준으로 가장 중요한 사용자 시나리오/입출력 흐름 하나를 끝까지 구현해라. 필요한 경우 Auth→서버측 권한→DB/API→UI를 연결하고, UI 불필요 과제에서는 입력→변환/계산→출력→검증으로 구현해라. 가능한 빠르게 실행 상태를 만들고 기본 테스트 후 실제 결과만 보고해라. 불필요한 페이지, 미관, 리팩터링, 매 단계 별도 QA는 보류한다. 원본 데이터는 수정하지 마라.
```

**완료 조건:** 실행 명령, 실제 입출력 샘플, 검사 통과/실패, 남은 필수 요구사항. Main이 소유.
