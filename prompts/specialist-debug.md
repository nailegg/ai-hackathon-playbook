# Repair Explorer (읽기 전용 보조 세션)

> **대상: 두 번째 Codex 세션에 붙여 넣는 프롬프트.** 사람이 Terminal 2에서, 해당 전략 문서의 "허용되는 분할" 조건에 맞을 때만 띄운다. 동시에 1개, 10분 안에 끝낸다. Main 세션은 이 세션을 띄우지 않는다.

```text
과제 루트에서 실행 중이다. 너는 읽기 전용 보조 세션이다. 과제 README.md와 CONTRACT.md를 먼저 읽어라. 코드·데이터·다른 문서는 수정하지 말고 결과는 REPAIR_MAP.md 한 파일에만 쓴다. 다른 세션이 같은 폴더에서 구현 중이니 서버를 띄우거나 종료하지 말고 패키지를 설치하지 마라. 10분 안에 끝내고, 명시된 사실과 가정을 구분해 1페이지 이내로 쓴다.
README·실행 스크립트·테스트 실패 로그를 보고 실패 테스트별로 재현 명령, 호출 경로(파일:함수), 가장 가능성 높은 원인 1~3개, 최소 수정 방향, 회귀 위험을 표로 정리한다. 테스트 실행은 해도 되지만 코드는 수정하지 마라(git restore·checkout도 하지 않는다).
```
