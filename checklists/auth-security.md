# Auth / RBAC 최소 필수 확인 (Auth가 요구된 과제에만)

- [ ] 비밀번호 안전한 해싱, 비밀키 환경변수, 기본 개발 계정/비밀번호의 제출 노출 위험 확인
- [ ] 로그인, 로그아웃, 만료된 세션 시 동작
- [ ] 미인증 사용자는 보호된 API에서 401 또는 의도된 거부
- [ ] 일반 사용자의 관리자 API 호출은 403 또는 의도된 거부
- [ ] 다른 사용자 소유 리소스 접근·수정 제한
- [ ] 서버에서 매 요청 실제 세션/권한 확인 — UI 숨김만으로는 불충분
- [ ] 입력 검증, DB 변경 후 새로고침에도 영속성
- [ ] 관리자/직원 시드 계정은 필요할 때만 만들고 README 설명
- [ ] 실제 API 요청으로 허용·거부 케이스를 각각 실행

**시험 중 금지:** 외부 서비스에 사용자·시험 데이터 무단 전송, API 키 코드/로그 노출, 검증 없는 즉흥 인증 프로토콜 설계.
