# 최적화 정식화 (사람이 5분 안에 직접 채우거나, OR 보조 세션이 채운다)

> 근거가 README에 있으면 `README §` 표시, 없으면 "가정"으로 쓰고 DECISIONS에도 한 줄 남긴다.

| 항목 | 내용 |
|---|---|
| 결정변수 (무엇을 정하나) | 예: 직원 → 버스 배정, 버스별 정류장 방문 순서 |
| Hard constraints (각각 검증 가능해야 함) | 예: 버스 정원 이하, 모든 직원 배정, 도착 시각 ≤ 출근 시각 |
| Soft objective (방향·단위) | 예: 총 이동거리(km) 최소화 |
| 모호한 목적함수 처리 | 예: 거리 최소화를 1순위, 탑승 시간 편차는 동률일 때만 |
| Baseline (20분 안에 구현) | 예: 정원 고려 greedy 배정 + 최근접 순서 |
| 개선안 1개 (필수 AC 끝난 뒤에만) | 예: 2-opt 순서 개선 |
| 독립 검증 사례 | 예: 정원 초과 0건, 미배정 0건, 작은 입력 수기 계산과 일치 |
| 실행 시간 제한·fallback | 예: 5초 timeout, 실패 시 baseline 결과 반환 |
